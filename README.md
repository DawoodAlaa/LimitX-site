# LimitX Official Site

الصفحة الرسمية لتحميل LimitX على Android وWindows، مع صفحة واضحة لتحديث العملاء القادمين من داخل التطبيق.

## التشغيل المحلي

هذا موقع static ولا يحتاج build step. شغّله بأي خادم ملفات، مثل:

```powershell
py -m http.server 8080
```

ثم افتح `http://localhost:8080`.

يقرأ `app.js` أحدث رقم إصدار من `/api/version` على سيرفر LimitX. أثناء تعطل السيرفر القصير، يحتفظ الموقع بآخر إصدار معروف ويستخدم روابط GitHub Releases الرسمية كخطة بديلة.

## النشر

المجلد مستقل عن كود تطبيق LimitX وسيرفره، ومناسب لـ GitHub Pages أو Cloudflare Pages. ملفات APK وWindows تبقى في مستودع الإصدارات العام، بينما يظل كود التطبيق والسيرفر في مستودعاتهما الخاصة.
